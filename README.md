# GB Browser

**GB Browser** is a high-performance, privacy-first Android web browser engineered with Jetpack Compose, Material Design 3, hardware acceleration (optimized for 90Hz/120Hz displays including Realme Note 60), and real-time on-device tracking protection.

---

## 🚀 Key Features

- **🌐 Globe Identity & Custom GB Branding:**
  - Modern globe vector insignia with "GB" brand mask.
  - Adaptive launcher icons and spring-animated splash transitions.

- **🔍 Fullscreen Search & History Hub:**
  - Dedicated search overlay with comfortable typography and instant autofocus.
  - Search engine selector with real vector brand logos (Google, Bing, DuckDuckGo, Brave, Ecosia, Yahoo, Startpage, Yandex).
  - Search query history manager with single-tap delete buttons ('X') for individual search items and a "Clear All" option.
  - One-tap clipboard paste chips and quick-destination launchpad.

- **📱 Hardware Navigation & Back-to-Home:**
  - Physical back button and UI back button immediately navigate back to the home screen (New Tab Page).
  - Realme Note 60 ergonomic 48dp+ interactive touch targets with ripple effects.

- **🎨 High-Quality Vector Logos (No Emojis):**
  - Crisp vector logos for Google, YouTube, GitHub, Wikipedia, Reddit, X (Twitter), Maps, Amazon, TechCrunch, and more.

- **🛡️ Built-in Privacy Shield:**
  - Zero-latency local ad and telemetry blocker.
  - Real-time tracker blocking counter and domain inspector.

- **⚡ Standalone APK Included:**
  - Ready-to-install `GB.apk` included directly in the `download apk/` folder.
  - Fully compatible with Android 6.0 (Marshmallow, API 23) through Android 16+ (API 36).

---

## 📦 How to Download and Install the APK

1. **Via AI Studio Export:**
   - In Google AI Studio, click **Settings / Export** and choose **Download ZIP** or **Push to GitHub**.
   - Open the extracted folder and navigate to `download apk/GB.apk`.
2. **Transfer to Device:**
   - Copy `GB.apk` to your phone via USB cable, Google Drive, or local file transfer.
   - Tap the APK on your device to install.
